Le scénario arrive plus souvent qu'on ne le croit, et toujours au mauvais moment. Le site affiche « This service is expired ». Ou les e-mails ne partent plus. Ou vous voulez refaire le site et vous découvrez que le nom de domaine est enregistré au nom de l'agence qui l'a créé en 2017, et que cette agence n'existe plus. Ou la personne qui s'occupait de tout est partie, ou décédée, avec les mots de passe.

Voici comment on s'en sort, dans l'ordre où on le fait quand une entreprise nous appelle avec ce problème.

## D'abord, comprendre ce que vous possédez

Un site internet, ce sont trois choses séparées, qui peuvent être chez trois prestataires différents et à trois noms différents :

- **le nom de domaine** (votre-entreprise.fr), loué chaque année auprès d'un bureau d'enregistrement ;
- **l'hébergement**, le serveur où vivent les fichiers du site, loué lui aussi ;
- **le site lui-même**, les fichiers, la base de données, les textes et les photos.

Le nom de domaine est de loin le plus important. C'est votre adresse, celle qui est sur vos cartes de visite, vos véhicules, vos factures, et c'est elle que Google connaît. Un site se reconstruit. Un nom de domaine perdu, lui, peut être racheté par n'importe qui le jour où il expire.

## Étape 1 : vérifier à qui appartient le nom de domaine

Faites une recherche Whois sur votre nom de domaine (pour un .fr, directement sur le site de l'Afnic, qui gère l'extension). Vous obtenez :

- le **titulaire** : la personne ou la société propriétaire du nom. C'est ce qui compte ;
- le **bureau d'enregistrement** (le registrar) : la société chez qui le nom est loué ;
- la **date d'expiration**.

Trois cas de figure :

1. **Le titulaire, c'est vous ou votre société.** Bonne nouvelle : le domaine est à vous, même si vous n'avez pas les accès. Il vous faut récupérer le compte chez le bureau d'enregistrement, ou transférer le domaine vers un bureau où vous avez un compte.
2. **Le titulaire, c'est le prestataire.** Le domaine ne vous appartient pas juridiquement. Il va falloir obtenir qu'il vous le transmette, et c'est là que la médiation entre en jeu.
3. **Le titulaire est masqué** (protection des données). Le registrar sait qui c'est : contactez-le avec vos justificatifs (Kbis, factures du prestataire mentionnant le domaine).

Regardez aussi la date d'expiration. Si elle est proche, tout le reste devient urgent.

## Étape 2 : récupérer ou transférer le domaine

**Si le domaine est à votre nom** mais que vous n'avez pas les accès, le bureau d'enregistrement dispose d'une procédure de récupération de compte sur justificatifs. Elle prend quelques jours. Vous pouvez aussi demander un transfert vers un autre bureau d'enregistrement : il faut pour cela le code d'autorisation du domaine (appelé code auth, ou AUTH_INFO), que le titulaire peut obtenir auprès du bureau actuel. Une fois transféré, le domaine est chez vous, avec vos accès.

**Si le domaine est au nom du prestataire**, c'est une transmission, un changement de titulaire, et elle demande son accord. Commencez par le lui demander par écrit, en rappelant que le domaine porte le nom de votre entreprise et que vous l'avez payé dans ses factures. Beaucoup de prestataires acceptent dès la première demande : enregistrer le domaine à leur nom était une facilité, pas une stratégie.

**S'il ne répond pas ou refuse**, l'Afnic propose depuis 2023 un service de médiation gratuit, facultatif, qui intervient avant toute procédure de règlement des litiges ou action en justice. Il concerne les noms en .fr (et .re, .pm, .tf, .wf). Ce que disent ses bilans publics :

- parmi les situations traitées figurent explicitement le nom de domaine enregistré par un prestataire web défaillant, et le nom enregistré au nom d'un prestataire qui ne répond plus ;
- en 2025, 63 % des médiations ont abouti à un accord, et trois accords sur quatre ont été conclus sans contrepartie financière ;
- l'immense majorité des accords porte sur la transmission du nom de domaine, et le bilan 2024 faisait état d'un accord trouvé en quatre jours ouvrés en moyenne.

La médiation suppose que l'autre partie accepte d'y participer. Si elle ne répond pas du tout, il reste la procédure de résolution des litiges de l'Afnic ou le tribunal, avec un avocat. Dans ce cas, rassemblez les preuves que le domaine est associé à votre activité : factures du prestataire, supports imprimés, archives du site, dépôt de marque si vous en avez un.

Pour un .com ou une autre extension, la logique est la même (titulaire, registrar, code de transfert), mais la médiation de l'Afnic ne s'applique pas : on passe par le registrar, puis par une procédure internationale si nécessaire.

## Étape 3 : récupérer l'hébergement et les fichiers

Pendant que le domaine se règle, le site peut disparaître si l'hébergement expire. Deux réflexes :

- **Contactez l'hébergeur** avec vos justificatifs. Si l'hébergement est au nom de votre société, vous pouvez récupérer le compte. S'il est au nom du prestataire, l'hébergeur ne vous donnera pas l'accès, mais il peut parfois vous indiquer la date d'expiration et, selon ses conditions, conserver les données quelque temps après.
- **Sauvegardez ce qui est encore en ligne.** Tant que le site s'affiche, on peut en récupérer les pages, les textes et les images. Si le site a déjà disparu, les archives publiques du web (la Wayback Machine) en conservent souvent une copie, parfois sur plusieurs années. Ce n'est pas le site d'origine, mais c'est de quoi reconstruire sans repartir d'une page blanche.

Les e-mails sont le point sensible : s'ils sont hébergés avec le site, ils tombent avec lui. Dès que vous avez la main sur le domaine, faites pointer les e-mails vers un service indépendant de l'hébergement du site. Vous ne revivrez plus ça.

## Étape 4 : reconstruire, à votre nom cette fois

Une fois le domaine récupéré, deux options : remettre en ligne l'ancien site à partir des sauvegardes, ou profiter de l'occasion pour le refaire. Dans les deux cas, trois règles pour ne pas retomber dans le même piège :

1. **Domaine, hébergement et site au nom de votre société**, avec un compte qui vous appartient. Un prestataire travaille sur vos comptes, pas l'inverse.
2. **Un coffre d'accès** : tous les identifiants (domaine, hébergement, administration du site, fiche Google, réseaux) dans un gestionnaire de mots de passe partagé entre deux personnes de l'entreprise. Si l'une part, l'autre a tout.
3. **Un rappel avant chaque échéance** : domaine, hébergement, boîtes mail. Soixante jours avant, puis trente. Un site qui disparaît pour une facture oubliée, c'est évitable.

C'est ce qu'on met en place pour chaque site qu'on livre, et c'est écrit dans le devis : si vous travaillez avec nous dans le cadre du [forfait communication](/forfait-communication-pme), la fiche d'accès vous est remise à la livraison, et les rappels d'échéance sont compris.

## Si vous êtes bloqué maintenant

Envoyez-nous le nom de domaine et ce que vous savez de la situation. On fait les vérifications (titulaire, registrar, expiration, ce qui est encore récupérable en ligne) et on vous dit par écrit ce qui est possible, dans quel ordre, et ce qui relève de la médiation ou d'un avocat. Cette première lecture est gratuite. La reprise du site, si vous la souhaitez ensuite, se fait sur devis, avec le domaine à votre nom dès le premier jour.
